# Melhorias e Acompanhamento de Progresso - Pyeduc 🚀

1. Arquitetura e Organização do Código (Alta Prioridade)

[ ] GUI monolítica: O arquivo gui.py (~770 linhas em uma única função main_app) viola princípios de responsabilidade única.
    Melhoria sugerida: Refatorar para uma abordagem baseada em componentes ou classes. Exemplo:
    LessonView.py (renderização de lições), ConsolePanel.py, TutorPanel.py, SidebarProgress.py
    Benefício: Mais fácil testar, manter e reutilizar.

[PARCIAL] Falta de modularidade em alguns módulos: Lógica de execução, persistência, conteúdo e IA já foram separadas (executor.py, progress_manager.py, content_manager.py, llm_client.py, tutor_guardrails.py), mas a UI permanece centralizada em gui.py.


2. Testabilidade e Qualidade de Código

[CONCLUÍDO] Suíte de testes automatizados criada:
    [X] Testes unitários para executor.py (validação AST, timeout, erros), content_manager.py, progress_manager.py, llm_client.py e tutor_guardrails.py (27 testes passando via pytest).
    [PARCIAL] Testes de integração e validação de currículo.
    [CONCLUÍDO] Integração Contínua (CI) via GitHub Actions (.github/workflows/build.yml).
    [ ] Linting + formatação rígida no CI (ruff + black).


3. Conteúdo Didático e Currículo

[CONCLUÍDO] Expansão significativa do currículo (Aulas 0 a 32 + Provas Práticas):
    [X] Módulos intermediários implementados: Tuplas, Dicionários, Conjuntos (Sets), Aprofundamento em Funções (parâmetros/escopo), Módulos Nativos (math, random, datetime), Tratamento de Erros (try/except), Manipulação de Arquivos (open/read/write) e Introdução a OOP.
    [X] Lições com dificuldade progressiva e projetos integradores: Prova Prática 1 (Lógica de Calculadora), Prova Prática 2 (Gerador de Nicknames e Senhas) e Prova Prática 3 (Gerenciador de Tarefas e Cadastro).
    [ ] Suporte a multi-linguagem no JSON (português + inglês).
    [ ] Exercícios com dicas adaptativas baseadas no histórico do aluno.

5. Inteligência Artificial e Tutor

[CONCLUÍDO] Aprimoramentos do Tutor IA (Ollama REST + Guardrails):
    [X] Suporte a múltiplos modelos e fallback automático (resolve_best_model prioriza qwen2.5-coder:1.5b, 3b, deepseek-coder, codellama, etc.).
    [X] Sistema de guardrails sócraticos (tutor_guardrails.py) com respostas estritamente em 3 tópicos e proibição de entregar código pronto.
    [X] Memória de conversa isolada por lição com reset automático ao trocar de aula.
    [X] Análise estática avançada via AST Python antes do prompt (detecta SyntaxError, NameError, variáveis não usadas, sobreescrita de builtins, loops infinitos sem break).
    [X] Descarregamento inteligente da VRAM (keep_alive: 0 via unload_model) ao fechar o app.
